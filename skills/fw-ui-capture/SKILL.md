# 游戏 UI 截图审阅

把用户指定范围的真实界面整理成可逐张反馈的图库。先建立覆盖清单，再截图；图片数量不能代替覆盖率。默认只采集和整理，不顺便重做 UI。

## 确定覆盖范围

- 沿用当前工程、用户选定的版本和分辨率；未知时从启动入口、项目配置和现有运行窗口确认。`fw` 前缀不要求游戏使用 FWC，不安装框架或改运行时。
- 用户说“所有 UI”时，查入口场景、页面路由、Form/Panel/Prefab、模态分发、教程与测试夹具，同时从游戏入口实际遍历，互相补漏。先形成 `coverage` 清单，不只截当前可见页。
- 清单以“界面 + 可见状态”组织：如有／无存档，选择／禁用，空／满，战前／战中／暂停／结算，弹窗，长按／悬浮提示，分页／滚动末尾。仅在画面有实质差异时增加状态，避免穷举无意义组合。
- 共用模板按普通、最长文本、空内容、精英/Boss等真实差异取样；用户明确要求每张卡或每个角色时才逐项展开。默认使用项目默认比例；有适配要求或已知溢出时增加代表性短屏／窄屏。
- 单页或单张请求只覆盖指定范围，不扩展为全项目审计。保留不可达项及原因；已删除或不在范围的入口标为排除，不伪造截图补齐。
- 仅整理已有图片时，覆盖清单限于提供的图片与状态，标题及证据写明原始来源；不能从该批覆盖率推断全游戏覆盖。图片是否属于本图库的采用集合与是否来自最新构建是两件事：未被替换的既有图可供正常审阅，不因拍摄日期早而一律标历史。

## 采集真实画面

按 [运行端采集](references/capture-runtime.md) 选择项目现有测试入口、引擎截屏或可用浏览器／电脑控制工具。缺少某种工具时说明限制，继续能完成的部分。

1. 记录运行版本、时间、窗口／视口尺寸和证据来源，使用独立存档或浏览器上下文。避免覆盖玩家进度；需要状态夹具时优先复用已有测试设施。
2. 通过真实入口或可复现夹具到达目标，让实际游戏组件渲染。记录必要的操作路径及状态；夹具截图明确标明，不冒充完整玩家流程。
3. 等待资源和页面稳定；战斗、动画、提示等用可复现时刻，避免任意长睡眠。截取真实 PNG，不用 Imagegen、拼图、重绘或 DOM 模拟替代游戏截图。
4. 按清单核对画面与入口，检查资源缺失、遮挡、裁剪及意外滚动；发现的问题写入备注，除非用户要求修复，否则保持截图中的真实问题。
5. 保持同批输入稳定。若并行修改影响截图对应版本，仅重拍受影响项或拆分为独立批次；不把混合版本称为同一当前版本，也不为纯截图强制执行整套游戏回归。

“captured”只表示已获得可检查的画面，不表示 UI 正确、交互测试通过、手机实机通过或全流程通过。核对后才把清单项标为 captured；不能到达时标 blocked，并给出具体原因。

## 生成图库

按 [清单格式](references/manifest.md) 写 `capture.json`。稳定语义 `id` 用于识别状态，正整数 `number` 用于用户引用；按页面流程分配编号。每张图保存真实宽高、证据和简短标题。

默认将过程与夹具放入项目的临时目录，交付图库放入项目约定的产物目录。FW 工程通常为 `.local/ui-capture/<run>/` 与 `output/ui-capture-<run>/`；其他工程尊重已有约定。

用技能目录中的 [图库生成器](scripts/build-gallery.mjs) 构建一个**尚不存在**的输出目录（Node.js 20.10+，无第三方依赖）：

```text
node <skill-dir>/scripts/build-gallery.mjs --manifest <capture.json> --out <new-gallery-directory>
```

它校验清单、PNG尺寸与覆盖引用，原样复制图片，生成可离线打开的 `index.html`、`capture.json` 和 `coverage.json`。支持分类、搜索、历史筛选、编号直达、原图、放大、上一张／下一张、问题备注和备注 JSON 导出。它不会启动游戏，也不能从 PNG 自动证明采集真实性。

- 打开实际生成的图库，检查首张、长文本／特殊尺寸及末张；验证筛选、编号定位、图片加载和备注功能。本机 HTML 即可，已有本地 HTTP 服务也可使用；不默认上传公开网站。
- 备注只存当前浏览器／当前源，可导出 JSON 保存。不同文件路径、端口或浏览器不保证共享备注；不要把页面存储当作服务端归档。
- 更新截图集时保留原 `id`、编号和原图字节；旧图标为 `historical`，新图使用新 `id` 和递增编号。只将真正替换的状态转历史，保留旧图库，构建新目录；当前覆盖引用新的截图。备注可先导出，避免丢失。

## 交付与停止

完成约定清单、核验图库后停止。简短给出图库入口、当前覆盖项数／未覆盖项和实测边界。部分可达也交付，明确列出 blocked／excluded；历史截图不计当前覆盖。截图请求本身不授权提交、推送或对外上传。
