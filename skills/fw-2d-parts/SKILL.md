# 2D 角色拆件

把现有角色整理成美术能查找、编辑和返稿的素材包。沿用宿主资源和渲染器，不要求安装 FW；仅导出不改变游戏采用的素材。

1. **认准来源。** 从角色配置、发布清单和实际加载链确认当前版本，检查换装、表情及高清替换。区分角色数量与独立造型数量；共用造型保留别名映射。历史素材只按请求收录并单独标识。
2. **分清产物。** 完整效果图、同画布姿势图层、原尺寸部件、原画参考分别标注。图集按真实区域或 UV 提取，不能把整张图集或烘焙姿势称为可重新绑定的独立原画。只给整图时，裁切不能恢复被遮挡的关节。
3. **保持组装关系。** 按实际绘制顺序拆层，保留统一画布和透明留白，不逐层居中。记录 slot、attachment、纹理、位置及骨骼/UV 映射；共享纹理可去重，图层关系不能丢。隔离图层前固定完整角色的姿势、外观和纹理上下文，先核对固定前后整图一致。
4. **保留可编辑部件。** 头、眼、嘴、衣装、手脚、装备按现有结构导出；已独立的面部与换装源图不只交付合成结果。缺失的遮挡补面明确说明；补画与改绑定属于额外制作工作。
5. **核对透明与还原。** 检查尺寸、Alpha、内容和裁边，把图层按序叠回整图，查看代表角色与特殊装备。先判断 Alpha 编码，仅对确认预乘的导出物反预乘一次；原始 PNG 不随之批处理。半透明边误差同时看黑白底显示效果，不能只比较低 Alpha 的 RGB。
6. **按角色交付。** 每个角色放整图、拆分图层、源部件和对接资料；公共素材可共享。附总览、角色索引、来源版本/摘要和简短返稿说明。核对覆盖、文件引用及同批输入稳定后打包；缺件照实列出。

Godot、组合脸和网格拆层的具体做法见 [喵喵实例](references/meow.md)，仅在相关项目中读取。画布尺寸、目录名称和选取姿势按任务决定，不照抄实例常量。

完成指定素材包即停止；导出结果不等于动画或重新绑定已验收，也不自动提交、推送或上传。
